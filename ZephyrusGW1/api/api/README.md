# Guild Wars 1 API JSON (Zaishen, Weekly, Nicholas)

This repository provides JSON endpoints for a Discord bot.

## Files

- `zaishen.json`  — Daily Zaishen quests
- `weekly.json`   — Current weekly bonus
- `nicholas.json` — Nicholas the Traveler location and item
